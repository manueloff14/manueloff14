## Featured projects

### [Cero](https://cumbrecero.online) — Spanish conversational AI
A multi-LLM chat product I built solo. **30 active users with zero paid marketing**, **500+ chats** created in production. Frontend in Next.js + React. Backend orchestrates OpenAI, Anthropic Claude, and OpenRouter behind a unified model-routing layer.

> Founded · Designed · Built · Shipped · Operating

### [ColDrone Explorer](https://coldrone.onrender.com) — Public dataset visualization
Public-facing site for the first open dataset on drone attacks in Colombia. Built as part of **AI Safety Colombia × Apart Research**'s autonomous-weapons governance project. 39 geolocated incidents from official sources (Colombian Ministry of Defense, UN/OCHA, ICRC). Custom intensity metric (deaths×2 + injured).

**Stack:** Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · MapLibre GL · Recharts

> Three full-screen scroll-snap sections · Delivered in under 4 weeks

### Cumbre Empleos — Full Stack SaaS (2024-2026)
End-to-end job platform for Cundinamarca, Colombia. **Launched and operated in production for 18 months** on Linux + Docker infrastructure I self-hosted and administered. Paused by choice to focus on Cero.

**Stack:** Next.js · React · relational database · authentication · company-side dashboard · self-hosted

> Designed · Built · Launched · Operated 18 months · Self-hosted

### [Oli y Terra](https://github.com/manueloff14/oli-y-terra) — NASA Space Apps Challenge 2025 (Local Winner)
